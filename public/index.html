About The Project

Major Project Implementation combining AI and Web Technologies.

The Problem

Manually entering information from hundreds of certificates into a spreadsheet is tedious, time-consuming, and prone to human error. Institutions need a better way to archive achievements.

Our Solution

We built CertiAI, an intelligent web application that uses Google's latest Gemini AI models to analyze images, understand context, and accurately map certificate visual data into structured Excel formats instantly.

Tech Stack

  • Frontend: HTML5, CSS3 Glassmorphism, Vanilla JS
  • Backend: Node.js, Express
  • AI Engine: Google Gemini 2.5 Flash API
  • Data Handling: Multer, ExcelJS

Deploy CertiAI to Netlify

Learn how to deploy CertiAI with Netlify frontend + Render backend in under 5 minutes.

Architecture Overview

Because CertiAI extracts large batches of certificates (200–400 images) with OCR and image processing, the optimal architecture is:

  • Frontend (Fast Global CDN): Hosted on Netlify (100% Free)
  • Backend API (Persistent Node.js Server): Hosted on Render.com or Railway (100% Free)
  • Automatic Proxy: Netlify forwards all /api/* requests to Render transparently with 0 CORS issues!
  • Zero Database Required: No MySQL needed! Pure Excel spreadsheet generation and direct downloads for faculty members.
1
Deploy Backend to Render:

Push your repository to GitHub. Go to dashboard.render.com -> New Web Service -> Select your repo. Build Command: npm install, Start Command: node server.js.

2
Deploy Frontend to Netlify:

Go to app.netlify.com -> Add new site -> Import an existing project. Publish directory: public. In netlify.toml, replace the Render URL with your own!

3
Configure 3–4 Gemini API Keys:

Once deployed, faculty opens the web app and clicks 🔑 API Keys to enter their 3–4 Gemini keys. Keys are saved securely in faculty browser session!

Instant Netlify Drag & Drop

You can deploy the CertiAI frontend instantly without Git by dragging the public/ folder into Netlify:

  1. Open app.netlify.com/drop in your browser
  2. Drag and drop the public folder from your project into the browser box
  3. Your site is instantly live on https://your-site.netlify.app!
  4. Open your live site, click 🔑 API Keys -> Paste your Render backend URL and your 3–4 Gemini keys!
Zero Database Architecture

CertiAI operates in 100% Standalone Excel Mode. Faculty members can use it anywhere without installing, configuring, or connecting to MySQL:

  • No MySQL Required: Zero cloud database setup, zero connection strings, and zero maintenance.
  • Instant Excel Downloads: All extracted certificates are formatted directly into clean, standardized certificates.xlsx spreadsheets.
  • Open Access: Any faculty member or student can open the app, supply their Gemini API keys, process certificates, and export reports immediately.
